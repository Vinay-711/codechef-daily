# BTAR

[Original practice problem](https://www.codechef.com/problems/BTAR)

Date: 2026-11-06 (Asia/Kolkata). Status: **Accepted** (Correct Answer). Platform: **CodeChef**. Difficulty: **Hard (4-Star)**.

## Approach

Modulo-4 greedy pairing algorithm for Beautiful Array. Checks total sum divisibility by 4, pairs remainder 1 and 3, pairs remainder 2 with 2, and resolves remaining elements in groups of 4. Time Complexity: O(N) per test case, Space: O(1).
