[Original practice problem](https://www.codechef.com/problems/AMR15A)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **CodeChef**.

## Approach

The solution iterates through the input array of weapon counts, maintaining two counters: one for even numbers (lucky) and one for odd numbers (unlucky). After processing all soldiers, it compares the counts and prints 'READY FOR BATTLE' if the even count is strictly greater than the odd count, otherwise 'NOT READY'. Time complexity is O(N) and space complexity is O(1).
