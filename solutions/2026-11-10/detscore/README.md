# detscore

[Original practice problem](https://www.codechef.com/problems/DETSCORE)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **CodeChef**.

## Approach

The problem asks to calculate the score based on X total points divided into 10 test cases. Each test case is worth X/10 points. The total score for N passed test cases is (X/10) * N. The time complexity is O(T) where T is the number of test cases, and space complexity is O(1).
