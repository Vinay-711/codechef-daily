# taxsaving

[Original practice problem](https://www.codechef.com/problems/TAXSAVING)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **CodeChef**.

## Approach

To avoid taxes, the effective income (X - investment) must be less than or equal to Y. Therefore, X - investment <= Y, which simplifies to investment >= X - Y. The minimum investment is X - Y. Time complexity is O(T) and space complexity is O(1).
