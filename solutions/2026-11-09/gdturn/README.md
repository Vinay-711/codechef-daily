# gdturn

[Original practice problem](https://www.codechef.com/problems/GDTURN)

Date: 2026-11-09 (Asia/Kolkata). Status: **Accepted**. Platform: **CodeChef**.

## Approach

For each test case, we check if the sum of X and Y is strictly greater than 6. If X + Y > 6, the turn is good and we print YES; otherwise, we print NO. The time complexity per testcase is O(1) and the space complexity is O(1).
