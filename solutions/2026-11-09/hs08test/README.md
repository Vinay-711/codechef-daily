# hs08test

[Original practice problem](https://www.codechef.com/problems/HS08TEST)

Date: 2026-11-09 (Asia/Kolkata). Status: **Accepted**. Platform: **CodeChef**.

## Approach

The solution reads the withdrawal amount X and balance Y. It checks if X is a multiple of 5 and if X + 0.50 is less than or equal to Y. If both conditions are met, it subtracts X + 0.50 from Y. Otherwise, it prints the original balance. Time complexity is O(1) and space complexity is O(1).
